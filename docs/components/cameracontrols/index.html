CameraControls

implements IUpdatable implements IDisposable

轨道式相机控制器，移植自 camera-controls v3.1.2，改写为符合本工程规范的 TypeScript 实现。支持 PerspectiveCamera 和 OrthographicCamera，提供轨道旋转、dolly/zoom、truck/pan、边界约束、碰撞检测、可配置的鼠标/触控输入映射。所有带 enableTransition 参数的方法返回 Promise<void>，可 await 等待过渡完成。

示例

import { CameraControls } from '@cyc/3d-components/camera';

const controls = new CameraControls({
  camera,
  domElement: renderer.domElement,
  smoothTime: 0.3,
});

// 编程式旋转
await controls.rotateTo(Math.PI / 4, Math.PI / 3, true);

// 适配到对象
await controls.fitToBox(myMesh, true);

// 每帧更新
const clock = new THREE.Clock();
function frame() {
  const dt = clock.getDelta();
  controls.update(dt);
  renderer.render(scene, camera);
  requestAnimationFrame(frame);
}
