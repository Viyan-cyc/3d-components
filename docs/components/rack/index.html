Rack

extends THREE.Group import @a3d/a3d-components/core implements IDisposable

仓储货架组件。立柱 + 横梁构成框架、层板承载货物，全部构件复用同一个单位 BoxGeometry，经两个 InstancedMesh 实例化渲染——无论货架多大规模，始终只有 2 个 draw call。支持数量（等分）或数组（逐格尺寸）两种布局定义、三种层板模式，以及 set() 数据驱动的动态重建。原点在货架前缘左端：宽度沿 +X、高度沿 +Y、深度沿 -Z（正面朝 +Z）。

Constructor

new Rack(options?: RackOptions)

Parameters — RackOptions

参数类型默认值说明
dataRackData—初始货架数据。不传则创建空货架，之后可随时 set()
frameMaterialTHREE.Material—框架（立柱 + 横梁）共享材质。不传则使用默认 MeshStandardMaterial（白色）
plankMaterialTHREE.Material—层板共享材质。不传则使用默认 MeshStandardMaterial（木色 0xeac58b）
namestring—Object3D.name
visiblebooleantrue是否可见
userDataobject—自定义数据
childrenObject3D[]—额外子节点，自动 add()（set() 重建时保留）

Data — RackData（货架结构）

字段类型默认值说明
rownumber | number[]—必填。横向货位划分：数量 ⇒ 等分 row 个货位、每个宽 width；数组 ⇒ 逐货位宽度（此时忽略 width）。如 3 或 [1, 2, 1]
colnumber | number[]—必填。纵向层划分：数量 ⇒ 等分 col 层、每层高 height；数组 ⇒ 逐层高度（此时忽略 height）。如 3 或 [0.5, 1, 1.5]
widthnumber1每个货位的宽度，仅 row 为数量时生效
heightnumber1每层的高度，仅 col 为数量时生效
depthnumber—必填。货架深度（Z 方向）。正面在 z = 0、背面在 z = -depth
firstplanebooleanfalse最底层（y = 0）是否也生成层板 / 横梁。关闭时底层直接落地，首个层板位于第一层顶部
goodsPlankstring | number | RackPlank[]—层板模式：不传 ⇒ 每层一块通长实心层板；字符串 ⇒ 每货位一块，宽度为货位净宽的百分比（'60' ⇒ 60%）；数值 ⇒ 每货位一块固定宽度层板；数组 ⇒ 不自动生成，由数组显式指定每块层板

Data — RackPlank（显式层板）

字段类型默认值说明
positionVec3—必填。层板中心位置（货架局部坐标：x 沿宽、y 沿高、z 沿深）
widthnumber—必填。层板宽度（X 方向）
depthnumber—必填。层板深度（Z 方向）

Properties

属性类型说明
parametersReadonly<RackData> | null当前货架配置的独立副本（set() 合并后的结果，只读）

Methods

.set(data: Partial<RackData>): this

重建货架。与当前配置浅合并：只覆盖传入的字段，其余沿用上次配置——适配数据驱动的动态场景（如智能排布）。链式调用。

.copy(source: Rack): this

复制另一个货架：拷贝其变换与货架数据后整体重建，实例网格不与源实例共享；源实例上额外挂载的子节点递归克隆保留。

.dispose(): void

释放生成的实例网格、共享几何体；自建材质一并释放。

示例

import { Rack } from '@a3d/a3d-components/core';

// 4 货位 × 3 层、深 1m 的等分货架，每货位一块 60% 宽层板
const rack = new Rack({
  data: { row: 4, col: 3, width: 1.2, height: 0.8, depth: 1, goodsPlank: '60' },
});
scene.add(rack);

// 数据驱动重建：只改层数，其余沿用
rack.set({ col: 5 });

// 逐货位宽度 + 逐层高度 + 最底层层板
rack.set({
  row: [1, 2, 1],
  col: [0.5, 1, 1.5],
  firstplane: true,
});

// 显式层板：完全自定义每块层板的位置与尺寸
rack.set({
  goodsPlank: [{ position: { x: 1, y: 1, z: -0.5 }, width: 0.6, depth: 0.9 }],
});
