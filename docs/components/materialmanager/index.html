MaterialManager

implements IDisposable

材质管理器:按风格模板(dark/light/outdoor)管理材质配置,setTheme 一键换肤。copy 返回共享材质实例(换肤时直接改原对象、引用始终不变),clone(shareTexture=false) 返回独立材质 + 独立贴图(可各自改 repeat)。贴图经注入的 AssetCache 异步加载,就绪 / 换肤时回调通知。换肤时无需重新赋值 mesh.material、无需自己 dispose。

Constructor

new MaterialManager(options: MaterialManagerOptions)
选项类型说明
themesRecord<string, Theme>风格模板集合:theme 名 → 材质配置表
currentstring?初始 theme,默认第一个
assetCacheAssetCache?注入的缓存,用于贴图异步加载;未注入仅支持纯配色
onError(key, err) => void?错误回调(未知 key/theme、type 不一致、贴图失败、共享模式误用 repeat 等)
placeholderColorColorRepresentation?占位色:带贴图材质在贴图未就绪时填 color(避免闪白),就绪后恢复 config color(默认白)。无贴图材质不受影响

方法

方法签名说明
copy(key, cb) => Unsubscriber共享材质实例,换肤自动生效,引用不变
clone(key, cb, shareTexture=true) => Unsubscriber独立材质;shareTexture=false 连贴图独立(可各自 repeat)
setTheme(name) => Promise<void>一键换肤,所有订阅直接改写,贴图就绪后 resolve
getTheme() => string当前 theme 名
dispose() => void释放所有材质与 owned 贴图(共享贴图归 AssetCache)

核心不变式

引用不变 —— 换肤时直接改原材质对象的属性,不创建新对象。引用始终不变,初始 mesh.material = m 一次即可,后续换肤自动生效,无需重新赋值或释放旧材质。

类型固定 —— 同一 key 首次的材质类型被固定。新主题若声明不同类型会触发 onError 并跳过(不重建,否则引用会变)。同一 key 在各主题应保持类型一致。

共享贴图不可独立变换 —— copy 与 clone(shareTexture=true) 共用同一份 Texture,repeat/offset/rotation 改一处会牵连所有引用,故忽略并报 onError。需独立变换用 clone(shareTexture=false),生成独立贴图副本。

贴图字段三种写法 —— 每个贴图字段(如 map):写 { url } 让管理器加载应用;写 null 清除该贴图;不写则管理器不碰,保留你手动设的贴图。例:dark 写了 map、light 不写,切到 light 时 map 仍在;想去掉就写 map: null。

示例

import { MaterialManager } from '@a3d/a3d-components/material';
import { AssetCache } from '@a3d/a3d-components/loader';

const mm = new MaterialManager({
  themes: {
    red:  { car: { type: 'standard', color: 0xe94560, map: { url: '/car.jpg' } } },
    blue: { car: { type: 'standard', color: 0x4560e9, map: { url: '/car.jpg' } } },
  },
  current: 'red',
  assetCache: new AssetCache(),
  placeholderColor: 0x333333,
  onError: (k, e) => console.error(k, e),
});

// copy:共享材质实例。仅 init 时挂到 mesh,换肤时引用不变、自动生效
const unsub1 = mm.copy('car', (mat, reason) => {
  if (reason === 'init') meshA.material = mat;
});
const unsub2 = mm.copy('car', (mat, reason) => {
  if (reason === 'init') meshB.material = mat;  // 与 meshA 共享同一材质
});

// clone(shareTexture=false):独立材质 + 独立贴图,可各自改 repeat
const unsub3 = mm.clone('car', (mat, reason) => {
  if (reason === 'init') meshC.material = mat;
}, false);

// 一键换肤:所有材质 color 被直接改写,引用不变,无需重新赋值
await mm.setTheme('blue');   // meshA/B/C 同步变蓝

// 取消订阅
unsub1();     // copy:仅取消回调,共享材质不释放(meshB 仍正常换肤)
unsub3();     // clone:取消回调 + 释放独立材质和贴图

mm.dispose();  // 释放所有材质与 owned 贴图
