Animation

module

基于 GSAP 封装的通用动画库，完全隐藏 GSAP 概念。通过直观的链式 API 完成 Three.js 对象的动画编排与控制。

API

animate(target, config?): AnimationController

创建动画控制器。支持链式 .to() 串行、.parallel() 并行编排。

registerEasing(name, fn)

注册自定义缓动函数，注册后可通过名称在任何动画中使用。

setDefaultConfig(config)

修改全局默认配置（duration、ease、repeat 等）。

animate() 参数 — target

参数类型说明
targetObject3D | Object3D[]动画目标对象。传入数组时所有目标同步执行，共享进度。

animate() 参数 — AnimationConfig

参数类型默认值说明
toPropertyTarget—目标属性值。省略 from 时从当前值动画到 to。
fromPropertyTarget—起始属性值。设置后动画从 from 过渡到 to（或当前值）。
durationnumber1动画时长（秒）。
delaynumber0延迟启动时间（秒）。
easestring | (t) => number'easeInOut'缓动函数。内置名称如 'linear'、'easeOut'、'easeOutCubic' 等，或传入自定义 (t) => number 函数。
repeatnumber0重复次数。0 = 播放一次，1 = 共两次，以此类推。
yoyobooleanfalse是否往复播放（前进→后退→前进→…），需配合 repeat 使用。

PropertyTarget 属性目标

键类型说明
position{ x?, y?, z? }位置目标（局部坐标），只写需要动画的轴。
rotation{ x?, y?, z? }旋转目标（欧拉角，弧度制）。
scale{ x?, y?, z? }缩放目标。
'material.color'string材质颜色，支持十六进制字符串如 '#ff0000'。
'material.opacity'number材质透明度 (0-1)。
其他点路径unknown任意嵌套属性路径，如 'material.uniforms.uProgress.value'。

生命周期回调

回调签名说明
onStart() => void动画开始播放时触发。
onUpdate(progress: number) => void每帧更新时触发，progress 为当前进度 (0-1)。
onPause() => void暂停时触发。
onComplete() => void动画播放完成时触发。
onStop(progress: number) => void被 stop() 停止时触发，入参为停止时的进度。
onSeek(progress: number) => void跳转进度时触发。

AnimationController 方法

方法返回值说明
.to(props, config?)this添加串行动画步骤。第二个参数可覆盖 duration、ease 等配置。
.parallel(groups)this添加并行步骤组。groups 为回调数组，每个回调接收一个 AnimationStepBuilder。
.play()this开始播放。首次调用会构建内部 Timeline。
.pause()this暂停当前动画。
.resume()this从暂停处继续播放。
.stop()this停止播放并回到起始位置。
.restart()this重置到初始状态重新播放。
.seek(progress)this跳转到指定进度 (0-1)，不改变播放/暂停状态。
.getProgress()number获取当前播放进度 (0-1)。
.getState()AnimationState获取播放状态：'idle' | 'playing' | 'paused' | 'stopped' | 'completed' | 'destroyed'
.getDuration()number获取动画总时长（秒）。
.destroy()void销毁动画实例，释放所有内部资源。销毁后调用任何方法会抛出错误。

示例

1. 基础单步动画

传入 to 指定目标属性值，配合 duration 和 ease 完成单步动画。

import { animate } from '@a3d/a3d-components/animation';

animate(mesh, {
  to: { position: { x: 2 }, 'material.color': '#ff8800' },
  duration: 1,
  ease: 'easeOut',
  onComplete: () => console.log('完成'),
}).play();

2. 串行编排（链式 .to）

多次调用 .to()，步骤按顺序执行——前一步完成后执行下一步。

animate(mesh)
  .to({ position: { x: 2 } }, { duration: 0.5, ease: 'easeOut' })
  .to({ rotation: { y: Math.PI * 2 } }, { duration: 0.6, ease: 'easeInOut' })
  .to({ 'material.color': '#ff4488' }, { duration: 0.4, ease: 'easeIn' })
  .play();

3. 并行编排（.parallel）

.parallel() 中的所有子步骤同时开始播放。

animate(mesh)
  .parallel([
    (g) => g.to({ position: { y: 2 } }, { duration: 0.8, ease: 'easeOut' }),
    (g) => g.to({ rotation: { y: Math.PI } }, { duration: 0.8, ease: 'easeInOut' }),
    (g) => g.to({ 'material.color': '#ffff00' }, { duration: 0.8, ease: 'linear' }),
  ])
  .play();

4. 混合编排（串行 + 并行）

先移动，到达后同时旋转+变色，最后缩放——串行和并行自由组合。

animate(mesh)
  .to({ position: { x: 2 } }, { duration: 0.5, ease: 'easeOut' })
  .parallel([
    (g) => g.to({ rotation: { y: Math.PI } }, { duration: 0.5, ease: 'easeInOut' }),
    (g) => g.to({ 'material.color': '#ff0044' }, { duration: 0.5, ease: 'linear' }),
  ])
  .to({ scale: { x: 1.5, y: 1.5, z: 1.5 } }, { duration: 0.3, ease: 'easeOutBack' })
  .play();

5. 并行中嵌套串行

.parallel() 的每个回调是一个独立的并行轨道，轨道内部可以用 .to() 链式调用来编排串行步骤。两条轨道同时开始，但各自内部按串行执行：

  • 轨道 A（位置）：先向右移动 (0→0.5s)，到达后再向上移动 (0.5→1.0s)
  • 轨道 B（旋转）：绕 Y 轴旋转一圈 (0→0.8s)

两条轨道同时启动，总时长取最长的轨道 = 1.0s。

animate(mesh)
  .parallel([
    // 轨道 A：先右移，再上移（串行）
    (g) => g
      .to({ position: { x: 2 } }, { duration: 0.5, ease: 'easeOut' })
      .to({ position: { y: 2 } }, { duration: 0.5, ease: 'easeOut' }),
    // 轨道 B：旋转一圈
    (g) => g
      .to({ rotation: { y: Math.PI * 2 } }, { duration: 0.8, ease: 'easeInOut' }),
  ])
  .play();

6. from 动画

指定 from 起始值，动画从该值过渡到 to 目标值（或当前值）。

animate(mesh, {
  from: { position: { x: -5, y: 5 } },
  to: { position: { x: 0, y: 0.5 } },
  duration: 1,
  ease: 'easeOutCubic',
}).play();

7. repeat + yoyo

repeat 控制重复次数，yoyo 启用往复播放（前进→后退→前进→…）。

animate(mesh, {
  to: { position: { y: 2 } },
  duration: 0.6,
  ease: 'easeInOut',
  repeat: 3,   // 重复3次（总共播放4次）
  yoyo: true,  // 每次往复
  onComplete: () => console.log('所有重复完成'),
}).play();

8. 多目标同时动画

传入对象数组，所有目标同步执行同一动画，共享进度。适合所有目标做相同动画的场景。

animate([mesh1, mesh2, mesh3], {
  to: { position: { y: 2 } },
  duration: 0.8,
  ease: 'easeOutBack',
}).play();

9. 多目标 + 纯 onUpdate

传入对象数组配合 onUpdate，在回调中遍历每个目标实现自定义动画逻辑（如波浪、错开等效果）。

animate([mesh1, mesh2, mesh3], {
  duration: 1.5,
  ease: 'easeInOut',
  onUpdate: (progress) => {
    [mesh1, mesh2, mesh3].forEach((mesh, i) => {
      const offset = i * 0.15;              // 逐个错开
      const p = Math.max(0, Math.min(1, (progress - offset) / (1 - offset)));
      mesh.position.y = Math.sin(p * Math.PI) * 2;  // 波浪上升
      mesh.rotation.y = p * Math.PI * 2;             // 旋转
    });
  },
}).play();

多目标 vs parallel —— 如何选择？

场景用哪个原因
所有目标做同样的属性动画 animate([m1,m2], { to }) 简洁，一行搞定
所有目标统一驱动但逻辑可遍历区分 animate([...], { onUpdate }) 回调中用 index / 属性区分，如波浪错开效果
每个目标有完全不同的动画或回调 .parallel([...]) 每条轨道独立配置，各自有独立的 onUpdate/onStart/onComplete 
// ❌ 错误：多目标数组不支持各自的 onUpdate
animate([mesh1, mesh2], {
  onUpdate: (progress) => {
    // mesh1 和 mesh2 共享同一个回调，无法分别配置
  },
});

// ✅ 正确：各自不同的动画 → 用 parallel
animate(mesh)
  .parallel([
    (g) => g.to({ position: { x: 2 } }, {
      duration: 0.5,
      onUpdate: (p) => console.log('移动进度', p),
    }),
    (g) => g.to({ 'material.color': '#ff0000' }, {
      duration: 0.3,
      onUpdate: (p) => console.log('变色进度', p),
    }),
  ])
  .play();

10. 手动控制（play / pause / seek / stop / restart）

通过命令式 API 完整控制动画播放生命周期。

const anim = animate(mesh, {
  to: { position: { x: 2 }, rotation: { y: Math.PI } },
  duration: 3,
  ease: 'easeInOut',
});

anim.play();           // 开始播放
anim.pause();          // 暂停
anim.seek(0.5);        // 跳转到 50%
anim.resume();         // 继续播放
anim.getProgress();    // → 0.5
anim.getState();       // → 'playing'
anim.stop();           // 停止并回到起始位置
anim.restart();        // 重新播放

11. 自定义缓动

通过 registerEasing 注册自定义缓动函数，之后用名称引用。

import { animate, registerEasing } from '@a3d/a3d-components/animation';

registerEasing('customElastic', (t) => {
  if (t === 0 || t === 1) return t;
  return Math.pow(2, -10 * t) * Math.sin((t * 10 - 0.75) * (2 * Math.PI / 3)) + 1;
});

animate(mesh, {
  to: { position: { x: 2 } },
  duration: 1.5,
  ease: 'customElastic',
}).play();

12. 纯 onUpdate 模式

不指定 to/from，仅通过 onUpdate(progress) 回调驱动自定义逻辑。

animate(mesh, {
  duration: 2,
  ease: 'easeInOut',
  onUpdate: (progress) => {
    const s = 1 + Math.sin(progress * Math.PI) * 0.8;
    mesh.scale.set(s, s, s);
    mesh.rotation.y = progress * Math.PI * 2;
  },
}).play();
