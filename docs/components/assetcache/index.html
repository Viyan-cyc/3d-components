AssetCache

implements IDisposable

模型与贴图的按需加载 / 内存缓存组件。采用两层缓存：THREE.Cache（文件层，缓存原始字节）+ 内部 Map<url, Promise>（对象层，缓存解析后的 GLTF / Texture，并对并发请求去重）。注册时不加载，loadModel / loadTexture 时才发起网络请求，命中缓存后不再请求。模型与贴图 API 完全对称。

Constructor

new AssetCache()

使用 new AssetCache() 创建一个独立缓存实例。

注册与加载

方法签名说明
registerModel(key, url, options?)注册模型（不加载），options 仅首次加载生效
registerTexture(key, url, options?)注册贴图（不加载），options 仅首次加载生效
loadModel(key) => Promise<GLTF>按 key 加载模型，返回共享 GLTF 实例
loadTexture(key) => Promise<Texture>按 key 加载贴图，返回共享 Texture 实例
loadModelFromUrl(url, options?) => Promise<GLTF>直接按 URL 加载模型（无需注册）
loadTextureFromUrl(url, options?) => Promise<Texture>直接按 URL 加载贴图（无需注册）
preloadModel(key) => void后台预加载模型，不返回结果
preloadTexture(key) => void后台预加载贴图，不返回结果

克隆（clone）

方法签名说明
cloneModel(key, options?) => Promise<Object3D>克隆模型，默认最浅（全共享），options 控制哪些独立
cloneMaterial(material, options?) => Material单独克隆材质，控制 material / texture 共享

三种资源（geometry / material / texture）可各自决定共享与否，排列组合出多种克隆策略：

CloneOptions默认说明
shareGeometrytrue共享 geometry 引用（省内存）；false 复制独立几何，可独立变形
shareMaterialtrue共享 material 引用；false 复制独立材质，改色不串
shareTexturetrue共享 material 内 texture；false 复制独立 texture（仅 shareMaterial: false 时生效，image 数据仍共享）

查询与清理

方法说明
hasModel / hasTexture是否已注册
isModelLoaded / isTextureLoaded是否已加载完成并进入缓存
clearModel / clearTexture / clearAll移除缓存引用（不释放 GPU，安全，可重新加载）
disposeModel / disposeTexture / disposeAll释放 GPU 资源（克隆体 / 引用共享资源时慎用）

注意事项

复用：loadModel 返回共享实例，Object3D 只能有一个父节点，多处复用用 cloneModel。共享材质时改色会串，需独立改色传 shareMaterial: false 或用 AssetCache.cloneMaterial。

释放：clearModel / clearTexture 仅删引用可重载；disposeModel / disposeTexture 会释放 GPU 资源，若仍有克隆体 / 引用在用会导致其失效。

示例

import { AssetCache } from '@a3d/a3d-components/loader';

const cache = new AssetCache();

// 1. 注册（不加载）
cache.registerModel('robot', '/models/robot.glb');
cache.registerTexture('metal', '/textures/metal.png');

// 2. 按需加载（首次请求，之后命中缓存、不再请求）
const robot = await cache.loadModel('robot');
const tex = await cache.loadTexture('metal');
scene.add(robot.scene);

// 3. 克隆复用：默认浅拷贝（全共享，最省内存）
const a = await cache.cloneModel('robot');
scene.add(a);

// 4. 深拷贝（全独立，互不影响）
const b = await cache.cloneModel('robot', {
  shareGeometry: false, shareMaterial: false, shareTexture: false,
});
scene.add(b);

// 5. 自定义粒度：共享 geometry，独立 material（texture 仍共享）
const c = await cache.cloneModel('robot', { shareMaterial: false });
scene.add(c);

// 6. 单独克隆材质（独立材质 + 独立 texture）
const mat = cache.cloneMaterial(mesh.material, {
  shareMaterial: false,
  shareTexture: false,
});

// 7. 预热
cache.preloadModel('robot');
cache.preloadTexture('metal');

// 8. 从场景移除（缓存保留，重新 loadModel 瞬时命中）
scene.remove(robot.scene);

// 9. 清理缓存（重新 loadModel / loadTexture 将走网络请求）
cache.clearModel('robot');   // 移除模型缓存引用
cache.disposeModel('robot'); // 释放模型 GPU（确认无克隆体在用）
